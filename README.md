# gentle-hearth-web

My own project for a gentle health and wellness website.

This project is built with Next.js and includes a small identity/safety utility module.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the app.

## Project Structure

- `src/app` — app pages and layout
- `src/lib/safetyAndIdentity.ts` — identity-related helper logic
- `public` — static assets
